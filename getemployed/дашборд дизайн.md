## 6. ПОТОК СРАВНЕНИЯ (как нейронка + skill gap работают вместе)

```
Вход: Профиль пользователя (Java=4, Spring=3, SQL=2, ...)
      Текст вакансии (title + requirements + description)

Шаг 1: Нейросеть (Sentence Transformers)
  Text профиля: "Java Backend Developer, Java 4/5, Spring Boot 3/5, SQL 2/5"
  Text вакансии: "Senior Java Backend Developer required: Java, Spring, Kafka..."
  
  → Embedding профиля (768-мерный вектор)
  → Embedding вакансии (768-мерный вектор)
  → cosine_similarity = 0.89
  → sbertScore = 89%

Шаг 2: Skill Gap
  Требуемые навыки вакансии: [Java (must-have), Spring (must-have), Kafka (must-have), K8s (nice)]
  Мои навыки: [Java (4), Spring (3), SQL (2)]
  
  → Маппинг: Java ✓, Spring ✓, Kafka ✗, K8s ✗
  → Coverage = 2 out of 4 must-have = 50%
  → skillsCoverage = 50%

Шаг 3: Итоговый скор
  finalScore = 0.7 * sbertScore + 0.3 * skillsCoverage
             = 0.7 * 89 + 0.3 * 50
             = 62.3 + 15
             = 77.3% → округляем до 77%

Результат: 
  - Показываем пользователю "Match: 77% ██████████░"
  - Красные флаги: Kafka (must-have), K8s (nice-to-have)
  - План: "Выучи Kafka, потом Kubernetes"
```
